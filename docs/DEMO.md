# Демонстрация проекта

## Панель оператора

Ниже — реальный шаблон финансовой панели, заполненный **синтетическими данными**. Все числа вымышлены; скриншот не подтверждает выручку, число пользователей или эффективность рассылок.

![Финансовая панель Neyra: демонстрационные данные](assets/finance-demo.png)

[HTML-снимок панели](demo/finance.html) можно скачать и открыть в браузере. Для оформления и графика нужен интернет (CDN). Действия и переходы отключены; конфигурация, ключи и рабочие данные приложения не используются.

Для пересоздания снимка: `python scripts/render_demo.py` после установки зависимостей. Подробности — в [руководстве разработчика](DEVELOPMENT.md).

## Сценарий показа на собеседовании

1. Объяснить процесс: пользователь заказывает AI-результат, система учитывает баланс, выдаёт покупку и запускает коммуникации по событиям.
2. В [Telegram-боте](https://t.me/NeyraChatBot) показать `/start`, каталог сцен, `/status` и `/sub`. Генерация зависит от доступности сервиса и баланса. Не проводить реальные платежи для технической проверки.
3. Показать панель: выручка по дням, способы оплаты, пользовательская и платёжная воронки, результат напоминаний. Подчеркнуть, что цифры на снимке демонстрационные.
4. Открыть `payment_processing.py`: объяснить общую транзакцию для webhook и поллинга, защиту от дублей и конкуренции разных платежей.
5. Запустить тестовый контур из README: он проверяет ключевые сценарии на PostgreSQL и Redis без рабочих ключей.

Записи видео реального пользовательского сеанса в репозитории нет. Статический снимок показывает только интерфейс панели; прохождение сценария в Telegram нужно демонстрировать отдельно.
