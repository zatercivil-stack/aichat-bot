# Открытый код и работающий сервис

Открытый репозиторий содержит код, миграции, инструкции и демонстрационные материалы. Рабочая конфигурация остаётся на сервере: `.env`, API-ключи, Telegram-токен, пароли, база пользователей, фотографии и резервные копии не должны попадать в Git или Docker build context.

## Как связаны GitHub и production

GitHub хранит исходники. Работающий бот исполняет код внутри уже собранного Docker-образа и получает настройки при запуске. Публикация коммита сама по себе не заменяет этот образ и не перезапускает приложение. В CI этого репозитория нет шага автоматического развёртывания.

Обновление production — отдельная операция: проверить изменения и миграции, сохранить резервную копию, собрать образ, обновить сервис и проверить его состояние. Изменения, восстанавливающие фоновые задания подписок и коммуникаций, нужно учитывать при таком обновлении.

## Проверка перед публичным выпуском

- Gitleaks проверяет всю доступную историю Git, а не только текущие файлы.
- Дополнительная проверка сравнивает исходники и Git-объекты с реальными значениями закрытой конфигурации в памяти; значения не выводятся в лог.
- Личные идентификаторы администраторов и служебные адреса перенесены в конфигурацию. Старые эксплуатационные заметки исключены из публикуемой истории.
- Демонстрационная панель использует синтетические данные.
- CI запускает сканирование секретов и запрещает жёстко заданный Telegram ID администратора.

Результат сканера означает, что он не обнаружил совпадений со своими правилами. Изменения, содержащие новые интеграции или данные, всё равно требуют проверки перед публикацией.

## После очистки истории

Старая локальная копия может содержать прежние коммиты. Не объединяйте старую и очищенную истории и не отправляйте старые ветки обратно на GitHub: это вернёт удалённые сведения.

Для разработки проще создать свежий клон. Рабочую серверную копию следует согласовывать отдельно при подготовке развёртывания, сохранив локальную конфигурацию и данные. Если реальный токен или пароль когда-либо оказался публичным, удаление файла или коммита не заменяет отзыв и выпуск нового ключа.
